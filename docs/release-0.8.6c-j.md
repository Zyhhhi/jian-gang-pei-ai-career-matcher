# 简岗配 · RoleFit AI v0.8.6C-J 发布记录

发布日期：2026-07-20

## 本次修复

- 为 Schema 1.2 全部受限数组增加统一的安全归一化流程，避免模型返回合理的额外关键词或建议时整次分析失败。
- 所有数组先验证字段类型和每个项目的完整结构，再处理数量边界；被截取范围之外的非法项目仍会导致失败。
- 纯字符串数组会删除纯空项、执行 trim 和稳定去重，随后保留前 `max` 项。
- 对象数组在全量项目校验后保留前 `max` 项，不进行字段别名、模糊嵌套或内容补造。
- 数组安全截取只记录 `ARRAY_ITEMS_TRUNCATED` 和允许列表字段路径，不记录被删除内容或数量。
- 归一化后低于 `min`、项目类型错误、必要字段缺失、错误嵌套、字符串超长、JSON 解析失败或输出被模型截断时仍严格失败。
- 校验和归一化成功后可以正常显示并保存完整求职分析包，不自动发起第二次模型调用。

## 一致性验证

- 自带 Key 前端与 Worker 对全部受限数组执行相同的归一化语义。
- 表驱动测试覆盖每个数组的 `max+1` 与 `max+5`、字符串去空/trim/稳定去重、低于最小数量、非法尾部项目和脱敏 warning。
- 历史记录只保存归一化后的完整结果，不保存数组 warning、模型原文或用户输入。

## 安全状态

- 前端 `ENABLE_PLATFORM_AI=false` 保持关闭。
- Worker `PLATFORM_AI_ENABLED=false` 保持关闭，本次不部署 Worker。
- 模型、`temperature` 和 `max_tokens` 未调整。
- 本次不调用 DeepSeek、Worker 或 Supabase，不执行 migration，不修改 Secret。
