# 简岗配 · RoleFit AI v0.9.0

发布日期：2026-07-23

## 前端信息架构重构

- 将主操作改为四步工作流：添加简历、添加岗位 JD、选择分析方式、查看分析结果。
- 顶部固定导航新增独立的产品说明、注意事项、历史记录与账户入口。
- 产品说明以面试讲解为目标，覆盖问题背景、产品架构、三种 AI 模式、额度与隐私边界、迭代过程和项目职责。
- 注意事项仅保留用户使用规则与隐私提醒。
- 历史记录改为独立视图；账户、Magic Link、自带 Key、本地数据与反馈移入账户菜单。
- 分析结果改为匹配总览、简历优化、面试准备、求职材料四个标签页。

## 不变的业务边界

- 未修改 AI Prompt、Schema 1.2、Worker 地址、Worker 调用协议、平台额度、Supabase RPC、Magic Link、自带 Key 调用、本地存储键与历史数据结构。
- 平台 AI 保持正式开放；仅成功分析计入每日 5 次和每月 30 次额度。
- Worker 的异常恢复 Cron 每 2 分钟运行；浏览器断线时结果可能无法取回，但陈旧平台额度会自动释放。
